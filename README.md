# Чистка - разбор галереи свайпами (iOS 17+)

Всё работает локально на iPhone, без облака и интернета.

## Что умеет

- **Разбор**: карточки фото/видео. Влево - в корзину, вправо - оставить навсегда, вверх - потом. Есть кнопки и «отменить».
  Фильтры: всё / фото / видео / скрины. Видео проигрываются прямо в карточке, видно размер файла.
- **Потом**: отложенные, можно разобрать их отдельно.
- **Корзина**: проверить перед удалением (тап - вернуть), потом удалить одной кнопкой.
  iOS спросит подтверждение, файлы ещё 30 дней лежат в «Недавно удалённых».
- **Похожие**: ищет похожие и одинаковые фото (Apple Vision + хэш), показывает сколько групп,
  сколько лишних и сколько места освободится. В каждой группе лучшее фото оставлено, остальные отмечены.
  Ползунок «Чувствительность» меняет строгость без пересканирования.

Принятые решения запоминаются, повторно уже разобранное не показывается.

## Как собрать без Mac (через GitHub)

1. Создай репозиторий на github.com (публичный - сборки бесплатные без лимита;
   у приватного бесплатно около 200 минут macOS в месяц, одна сборка ~5 минут).
2. Залей туда содержимое этой папки (вместе с `.github`).
3. Вкладка **Actions** → **Build IPA** → дождись зелёной галочки → внизу скачай артефакт
   `SwipeClean-ipa` (это zip, внутри `SwipeClean.ipa`).

## Как поставить на iPhone с Windows

1. Установи **iTunes** с сайта apple.com (не из Microsoft Store) и **Sideloadly** (sideloadly.io).
2. Подключи iPhone кабелем, нажми «Доверять» на телефоне.
3. В Sideloadly перетащи `SwipeClean.ipa`, введи свой Apple ID, нажми Start.
4. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится).
5. Настройки → Основные → **VPN и управление устройством** → свой Apple ID → Доверять.

С бесплатным Apple ID приложение работает 7 дней, потом просто ещё раз нажми Start в Sideloadly
(разметка сохранится). С платным аккаунтом разработчика ($99/год) - на год.

## Если есть Mac

`brew install xcodegen && xcodegen generate`, открыть `SwipeClean.xcodeproj`,
выбрать свою команду в Signing и запустить на телефоне.
